# random library documentation 

**random library has have functions:**

rnd_randint() - gives a random number from two passed numbers

```lmnlang
lmport(random);
rnd_randint(1,10)
```

will give a number from 1 to 10

rnd_choice() - gives a random words on array

```lmnlang
lmport(random);
rnd_choice(["ruscmi","smirnow"])
```

execute "ruscmi" or "smirnow"

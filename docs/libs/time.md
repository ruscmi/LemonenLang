# documentation time library on lmnlang

The Time Library allows you to literally manage time

It has basic functions:

time_lmit() - makes the delay in the terminal as much as you have entered into the lmit() value

```lmnlang
lmport(time);
lmuck("Hello");
time_lmit(1);
lmuck("ruscmi")
```

time_current() - get time in your operation system

```lmnlang
lmport(time);
time_current()
```

execute time on your OS

time_zone() - will give the time from the region you enter

```lmnlang
lmport(time);
time_zone("Europe/Moscow")
```

execute current time on Moscow city
